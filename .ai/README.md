# Nexor AI Context

Este diretorio guarda referencias para negocio e interface.

- `context/business/`: escopo, atores, jornadas, regras operacionais e limites do produto.
- `design-system/`: tokens, componentes, padroes e regras visuais para Nexor e Biteplaner.

Edicoes de codigo continuam em `project/`. Antes de implementar feature relevante, consulte `context/business/`. Antes de implementar interface, consulte `design-system/`.
