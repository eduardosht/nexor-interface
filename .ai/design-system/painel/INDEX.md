# Painel Design System

Este diretorio define o canal `painel` do design system.

`painel` e a vertente oficial para:

- paineis administrativos
- paineis operacionais
- dashboards internos
- areas autenticadas de gestão
- tabelas, filtros, fluxos e shells de produtividade

## Relacao com marca

O canal `painel` não substitui a marca.

Ele funciona como uma camada complementar:

- marca: define identidade visual base
- canal `painel`: define densidade, comportamento e padroes de interface para trabalho interno

Exemplos:

- painel Nexor: `nexor` + `painel`
- painel Biteplaner: `biteplaner` + `painel`

## Arquivos

- `foundations.md`: principios e regras do canal
- `components.md`: componentes e patterns especificos de painel

## Quando ler

Leia este canal sempre que a interface envolver:

- admin
- operação
- tabelas e filtros
- dashboard
- workflows de manutencao, revisão, aprovação ou auditoria
